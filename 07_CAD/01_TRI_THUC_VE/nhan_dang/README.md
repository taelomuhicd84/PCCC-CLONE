Mỗi file một đối tượng; sửa luật nhận dạng nào thì mở đúng file đó. Luật người dùng dặn có ngày; mã thực hiện ghi ở đầu mỗi file.

| File | Nhận gì |
|---|---|
| `truc.md` | bóng trục, nét trục, khung trục; vùng chỉ trong trục ngoài cùng |
| `tuong_cot.md` | nét nào là tường, layer tường, hatch, cột theo hình (L1), kẹp mặt tường bỏ cột lồi, nội thất |
| `cua_thang_khu.md` | khép ô cửa, thang bộ, giếng / ô X, sảnh thang, WC, chữ khu (mái che, sân, hiện hữu, phòng bơm), hiên, hộp kỹ thuật |
| `phong_vung.md` | quy trình vùng (duyệt, xoá), luật vùng, plugin dựng phòng thế nào (Enter mọi phòng, bấm điểm) |
| `dam_khoang.md` | loại trần, kết cấu (mái kèo / sàn), dầm b x h, d = h − dày sàn, khoang vì kèo / dầm sàn |
| `ky_hieu.md` | block thiết bị có sẵn: `MA_VT`, `block_alias.json`, block tên lạ |
| `pdf.md` | PDF nhiều trang (mục lục), tỉ lệ, nhập nền, kiểm tỉ lệ bằng trục, lấy ký hiệu từ PDF mẫu |
