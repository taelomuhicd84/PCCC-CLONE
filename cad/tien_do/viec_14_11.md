## Gói A — quy trình vẽ 6 bước + tường, cửa + ADIM/CDIM (agent Opus, effort high)
Quy trình vẽ người dùng chốt 14/11, áp dụng mỗi khi người dùng đưa bản vẽ PDF:
1. Trục → 2. Tường → 3. Mặt bằng chi tiết (tường, vách ngăn, cửa) → 4. Thiết bị PCCC (báo cháy, chữa cháy) → 5. Dây báo cháy, ống chữa cháy → 6. Sơ đồ nguyên lý.
Mỗi bước: một gói `cad_chay` + ảnh `anh` cuối gói, soát (`doc`, `dem`) rồi mới sang bước sau.
- File được sửa: `cad/module/plugin/KienTruc.cs` (mới), `cad/module/plugin/Dim.cs` (mới), `cad/module/plugin/Spec.cs` (chỉ thêm dòng điều phối op mới),
  `cad/skills/TU_VUNG.md`, `cad/.claude/skills/tkpccc-ve-cad/SKILL.md`, `cad/.claude/agents/cad-thiet-ke.md`, `cad-ve.md`, `cad-kiem.md`,
  `cad/test/chay_thu.ps1`, `cad/layer/` (chuẩn layer tường, vách, cửa, kích thước nếu chưa có), `cad/README.md`.
- KHÔNG sửa `Lenh.cs` (lệnh mới đặt trong class riêng ở file mới), không sửa `module/ui/`.
- Thao tác spec mới: `tuong` (tường theo tim, dày `d`, có khe cửa), vách ngăn (tường mỏng, layer riêng), `cua` (cửa đi: khe + cánh + cung mở),
  `kt_chuoi` (chuỗi kích thước qua các điểm, khử điểm trùng hàng). Phòng vẽ bằng `tuong` phải để `vung_tu_dong` dựng được vùng (khe cửa ≤ `HO_CUA_M`).
- Lệnh gõ tay (tên CỐ ĐỊNH, gói B gọi từ palette): `PCCC_TRUC` (lưới trục: nhịp X, nhịp Y, điểm gốc), `PCCC_TUONG` (tường, hỏi dày; tuỳ chọn vách),
  `PCCC_CUA` (cửa trên tường có sẵn), `PCCC_ADIM` (dim đối tượng tự động), `PCCC_CDIM` (dim tiếp tục).
- ADIM theo mục 6 file tham khảo: quét cửa sổ cả lưới thiết bị; lọc Block / Line / Pline / tất cả; 2 mốc mép tường tuỳ chọn (Enter bỏ qua);
  phương X / Y / tự nhận theo điểm đặt đường dim; chiếu lên trục, gom toạ độ trùng trong ε (≈ 10 mm theo đơn vị bản vẽ) để một cột thiết bị chỉ ra một mốc,
  không sinh dim 0 hay chồng; chuỗi `RotatedDimension` trên layer + dimstyle hiện hành. CDIM nối tiếp chuỗi vừa tạo.

- File được sửa: `cad/module/plugin/BanQuyen.cs` (mới), `cad/module/ui/BanQuyenUi.cs` (mới, chỉ dùng API có sẵn của `GiaoDien`), `cad/module/plugin/Cau.cs`

  (đối số `phat_hanh`), `cad/module/banquyen/` (mới: app tạo key, Apps Script, hướng dẫn), `cad/data/ban_quyen/`, `cad/test/thu_ban_quyen.ps1`, `.gitignore`, `cad/README.md`.
- HỢP ĐỒNG KEY (plugin kiểm, app + Apps Script ký, phải khớp từng byte):
  - Mã máy: 16 ký tự hex HOA đầu của SHA-256(UTF-8(MachineGuid trong `HKLM\SOFTWARE\Microsoft\Cryptography` + "|TKPCCC")), viết `XXXX-XXXX-XXXX-XXXX`.
  - Nội dung ký: `TKPCCC1|<email chữ thường, bỏ khoảng trắng hai đầu>|<mã máy>|<hạn yyyy-MM-dd>` (UTF-8).
  - Chữ ký: RSA 2048, PKCS#1 v1.5, SHA-256. Key = base64url(nội dung) + "." + base64url(chữ ký); dấu "=" cuối có hay không đều nhận.
  - Khoá công khai: `cad/data/ban_quyen/khoa_cong_khai.xml` (RSAKeyValue, được commit), nhúng vào DLL lúc build `phat_hanh`.
    Khoá riêng KHÔNG BAO GIỜ vào repo (repo công khai): app lưu ở `%USERPROFILE%\TKPCCC_KHOA\`, Apps Script giữ trong Script Properties.
- Plugin: lưu `%APPDATA%\TKPCCC\ban_quyen.json` (email, key). Bảng `PCCC_BANQUYEN`: email, mã máy (nút chép), key, nút Kích hoạt / Đăng ký / Lấy key tự động, trạng thái, hạn.
  Chặn lệnh chỉ ở bản build `phat_hanh` (`/define:BAN_QUYEN`); build thường và bộ test không bị chặn. Khi chặn: mọi lệnh `PCCC*` trừ `PCCC`, `PCCC_BANQUYEN`, `PCCC_CAIDAT`, `PCCC_HELP`.
- App tạo key cho chủ (`TKPCCC.KeyGen.exe`, WinForms C#): tạo cặp khoá (xuất XML công khai + PEM PKCS#8 riêng cho Apps Script), ký key tay (email, mã máy, hạn).
- Tự động qua Google Drive: Google Sheet (+ Google Form hoặc web app Apps Script) nhận email + mã máy; trình kích hoạt theo giờ 5 phút quét hàng chưa có key,
  ký bằng `Utilities.computeRsaSha256Signature`, ghi key vào đúng hàng của email đó (tuỳ chọn gửi mail). Plugin nút "Lấy key tự động" gọi web app lấy key theo email + mã máy.
